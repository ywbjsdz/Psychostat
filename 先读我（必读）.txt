Psychostat —— 心理统计 / 量表编制(CTT) / 项目反应理论(IRT)（教学与研究辅助工具）
仅支持 Windows 10/11。本包是**免安装版**：已带 R 运行时与全部所需 R 包，无需联网安装。

★★★ 这是 v0.1.1 预览版，稳定性未知：统计结果的质量有据可查，但"在你电脑上能否顺利跑完"没人保证。
    请先读同目录下的  免责声明（必读）.txt  ——里面有免责声明、不能用于哪些场景、
    已知的三块未独立验证区域，以及出问题时该回传哪些信息。★★★

════════════ 开始使用（2 步） ════════════
1. 把压缩包里的**一个文件夹 Psychostat** 解压到任意位置都可以（桌面 / 文档 / D 盘的任意子目录都行）。
   解压后结构是这样的，三者都在同一个文件夹里：
       Psychostat\                  ← 工具本体（双击里面的 启动Psychostat界面.bat）
       Psychostat\runtime\R         ← 随包 R（含全部所需 R 包）
       Psychostat\runtime\Python    ← 随包 Python（含报告所需的 pandas / python-docx）
   启动器会**相对项目文件夹**自动找这两个运行时，因此**不再要求解压到 D 盘根目录**。
   （v0.1.0 要求 "D:\Psychostat + D:\Psychostat-R + D:\Psychostat-Python" 三个文件夹平级——
    这正是有人"解压后能上传数据却分析不了、复制到文档里反而好了"的原因：位置/权限一变就找不到运行时。）
   小提示：**别解压到需要管理员权限的位置**（例如 D:\ 根目录本身）；桌面、文档、D 盘下的子目录都可以。
2. 双击  Psychostat\启动Psychostat界面.bat
   （也可双击 启动心理统计.bat / 启动量表编制_CTT.bat / 启动项目反应理论_IRT.bat 用命令行菜单）

先验证环境是否正常：双击  Psychostat\运行离线自检.bat —— 用随包 R 跑统计与 IRT 断言，不需联网。
详细自测方法见 免安装版-测试方法.md；完整说明书见 Psychostat完整使用说明书.docx。

════════════ IRT 报告新增了什么（v0.1.1）════════════
IRT 结果报告与 HTML 网页报告里多了一节「估计方法与收敛诊断」，直接回答审稿人常问的几件事：
  参数用什么方法估计、迭代上限多少、收敛判据是什么、**是否收敛**、**实际迭代了几次**、
  能力量尺怎么识别、MAP 用了什么先验，以及 mirt / psych / GPArotation 与 R 的版本。
IRT 界面第 1 步也新增了「直接选择模型」下拉（不必只靠问答向导），自动推荐与手动指定并存。


════════════ 练手数据 ════════════
examples/simulated_datasets/ 内有 14 个模拟数据集（CTT 5 个、IRT 9 个），各带生成真值与可运行配置。


════════════ 不想用了想删干净 ════════════
双击 Psychostat\清理Psychostat环境.bat（或界面左侧「清理已安装环境」），确认后执行；
再把**整个 Psychostat 文件夹**删掉即可（随包运行时与项目内的 .psychostat\ 依赖库都在里面）。
没有服务、注册表项或开机启动项。


════════════ 本包不含什么 ════════════
- outputs/：历史分析结果 —— 你自己跑配置就会生成。
- notes/：内部工作区（历史交接与临时脚本）。
- CHANGELOG.md / CONTRIBUTING.md / docs/ 下的文档源文件 / SPSS 对照的独立 Word 版：
  都在 GitHub 仓库里，需要时到仓库取（SPSS 对照的全文已并入《输出验证文档》第一部分）。


════════════ 随包运行时的版本（不要随意升级）════════════
本包把**已经验证过的版本**冻结在内，请勿用"最新版"覆盖它们——换版本会让既有验证失效，
也可能让同一批数据两次跑出不同结果：
    R 4.5.2 ｜ mirt 1.46.1 ｜ psych 2.6.5 ｜ lavaan 0.6.21 ｜ ltm 1.2.0 ｜ TAM 4.3.25
    Python 3.14.2 ｜ pandas 3.0.3 ｜ numpy 2.4.6 ｜ python-docx 1.2.0 ｜ lxml 6.0.2
若确需升级：升完必须重跑 运行离线自检.bat 与 tests\smoke_test.ps1 -Full，全绿才算可用。
随包运行时各自的许可见 runtime\R\COPYING*、runtime\Python\LICENSE.txt 与各库自带的
*.dist-info 目录（R 为 GPL、pandas/numpy/lxml 为 BSD、python-docx 为 MIT）。
