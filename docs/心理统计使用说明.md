# Psychostat 心理统计分支使用说明（写给大二的你）

本分支把本科心理统计的核心方法整理成 21 个可运行模块，并在任何分析之前**自动**执行第 0 步**数据准备与异常值筛查**（缺失值审计、异常值筛查、完整性检查——不必手动选择，也不占用方法编号）。每个模块都：**用模拟数据跑一遍 → 输出与 SPSS 27 默认参数一致的表格 → 告诉你对应的 SPSS 菜单路径 → 教你怎么读结果、怎么写结果 句子 → 自动生成中英文 Word 结果报告**。表格按 SPSS 27 默认口径实现（合并方差 t、Type III 平方和、均值中心 Levene 等），多数统计量可与 SPSS 小数点后 2-3 位对上。**但这是代码级口径对齐，不是逐方法的外部基准比对**——仓库内没有 SPSS 输出夹具，混合设计（EM 均值 SE、被试内配对比较 SE）尚有已知差异；正式发表前请手工抽查关键表格。

## 快速开始

在本目录打开 PowerShell：

```powershell
.\run_stats_analysis.ps1
```

出现四选一菜单：

1. **教学演示全流程（推荐首次使用）**：21 种方法全部用内置模拟数据各跑一遍（每个方法先做前置描述统计/正态性检查），生成约 130 个文件，包括每个方法的数据文件、SPSS 式结果表、图、中文教学报告和中英文 Word 结果报告。
2. **选择方法分析（模拟数据）**：只跑你选的方法，体验流程。
3. **分析我自己的数据**：选方法 → 指定列名 → 分析你的 CSV/Excel/SPSS 文件。
4. **方法选择向导**：回答 3-4 个问题（因变量类型？几组？独立还是重复测量？），工具推荐方法并解释理由。

也可以直接运行总入口 `.\run_psychostat.ps1`，输入 1 进入本分支（菜单顺序：1 心理统计、2 CTT、3 IRT）。

## 快捷命令

```powershell
# 一键跑全部教学演示（等同菜单选项1）
.\run_stats_analysis.ps1 -Simulate

# 只跑一个方法（模拟数据）
.\run_stats_analysis.ps1 -Method two_way_anova

# 用自己的数据跑指定方法
.\run_stats_analysis.ps1 -Method independent_t -Data .\my_data.csv

# 使用 YAML 配置
.\run_stats_analysis.ps1 -Config .\stats_config.yaml

# 静默/AI 调用（逐行 JSON 日志）
.\run_stats_analysis.ps1 -Silent -ConfigJson .\examples\silent_stats_demo.json
```

`-Method` 可取：`descriptives` `normality` `one_sample_t` `independent_t` `paired_t` `one_way_anova` `two_way_anova` `rm_anova` `mixed_anova` `ancova` `correlation` `regression` `chi_square_gof` `chi_square_independence` `mann_whitney` `wilcoxon_signed` `kruskal_wallis` `friedman` `mediation` `moderation` `power`（多个用逗号分隔）。

## 21 个模块一览

| # | 方法 | 什么时候用 | SPSS 路径 |
|---|------|-----------|-----------|

| 2 | 正态性与方差齐性 | t/ANOVA 的前提：Shapiro-Wilk、K-S、Levene | 探索>带检验的正态图 |
| 3 | 单样本t | 样本均值 vs 常模/总体值 | 比较均值>单样本T检验 |
| 4 | 独立样本t | 两组不同的人 | 比较均值>独立样本T检验 |
| 5 | 配对样本t | 同一批人前后测 | 比较均值>配对样本T检验 |
| 6 | 单因素ANOVA | 1个自变量≥3组 + 事后比较 | 比较均值>单因素ANOVA |
| 7 | 两因素ANOVA | 主效应+交互+简单效应（三步闭环） | 一般线性模型>单变量 |
| 8 | 重复测量ANOVA | 同一批人测≥3次（Mauchly/GG/HF） | 一般线性模型>重复测量 |

| 11 | 相关+偏相关 | 连续变量关联；控制第三变量 | 相关>双变量/偏相关 |
| 12 | 多元回归+调节 | 多个X预测Y；交互与简单斜率 | 回归>线性（PROCESS Model 1） |

| 20 | 调节效应 | X的效应何时/对谁更强（简单斜率+交互图） | 回归>PROCESS（Model 1） |
| 21 | 功效与样本量 | 开题算N（对应G*Power，按需选用） | G*Power / SPSS 28+ |

## 怎么和 SPSS 对照（重点）

1. 打开结果目录（控制台最后会给出路径），找到 `NN_方法_data.csv`（UTF-8-BOM 编码，SPSS/Excel 可直接打开）。
2. SPSS：文件 > 导入数据 > CSV，选该文件。
3. 按该模块给出的"SPSS操作路径"点击（控制台输出和 `stats_report_zh.md` 里都有）。
4. 对照：SPSS 输出的统计量 ↔ 同目录 `NN_方法_*.csv`。例如 `04_independent_t_test.csv` 的两行 t/df/p 对应 SPSS"独立样本检验"表的两行；`06_one_way_anova_posthoc_lsd.csv` 对应"多重比较"表。

**与 SPSS 27 对齐的关键约定**：均值中心 Levene、Type III 平方和、球形假定 F（配 Mauchly + Greenhouse-Geisser/Huynh-Feldt 校正，校正行的 MS/df 按 ε 重算）、LSD/Tukey/Bonferroni 事后、偏 η²、非参数渐近 Z（含结点校正、双尾）、95% 置信区间、效应量 Cohen's d / φ / Cramér's V / ε² / Kendall's W。

## 第 0 步：数据准备与异常值筛查（datacheck）

**任何统计分析之前先跑这一步——它是自动的，你不需要在方法列表里勾选它。** 它对应 SPSS 的【分析 > 描述统计 > 探索】与【分析 > 缺失值分析】，
产出四组结果（文件前缀 `00_prep_*`，不占用方法编号，所以第一个被你选中的方法永远输出 `01_*`）：

| 内容 | 表 | 怎么读 |
|---|---|---|
| **缺失值审计** | 逐变量缺失数/比例、个案级缺失清单、整例删除影响 | 缺失 <5% 且分散多可接受；>20% 的变量要考虑剔除。整例删除会损失样本，先看损失了多少人 |
| **异常值筛查** | Z 分数与 IQR 双标准的汇总表 + 个案清单 | Z 规则（默认 \|Z\|>3）以标准差为单位；1.5×IQR 以四分位距为单位，不假设正态。**n<10 时 Z 有理论上限 (n−1)/√n，会漏报，此时看箱线图更可靠** |
| **完整性检查** | ID 重复 / 整行重复 / 常量列 / 取值越界 | 量表题出现 99、999 这类值多为缺失码被当成真实分数，必须核对原始数据 |
| **处理摘要** | 原始 N → 处理 → 最终 N | **写论文方法部分直接引用这段** |

### 处理方式（默认只报告、不改动数据）

```yaml
datacheck:
  missing_action: mean_impute   # report(默认,只报告) | mean_impute(均值插补) | listwise(整例删除)
  outlier_action: remove_by_z   # report(默认,只标注) | remove_by_z(按 |Z| 删除)
  z_cutoff: 3                   # |Z| 阈值
  scale_range: [1, 5]           # 可选：量表合法范围
  scale_vars: [sleep_quality]   # 可选：哪些变量按该量表计分（只有列在这里的才严格判越界）
```

交互运行时（双击启动器 / 图形界面）会**先报告问题再问你要不要处理**，直接回车 = 不处理。

### 三条重要说明

1. **顺序**：先算 Z 分数 → 先删异常个案 → 再对剩余数据均值插补。若先插补，插补值会把均值拉向中心、
   人为缩小 SD，使真实极端值"逃过" Z 检验。
2. **均值插补会缩小该变量的方差**，并削弱它与其他变量的相关 —— 这是它的已知代价，报告时必须写明用了插补与插补个数。
3. **异常值不一定是错误**：真实的极端被试也是数据。默认不删；若决定删除，论文里要写明判定标准与人数。

---

**对照时容易疑惑的 6 个点（都不是错误）**：
1. **配对/前后测方向**：本工具差值默认 = 后 − 前（dv2 − dv1），与 SPSS 变量列表按字母序点选配对时的方向一致（如 post 在 pre 前面点选即 后−前）；如需 前−后，在配置 analysis.paired_direction 设为 dv1_minus_dv2。|t| 与 p 值不受方向影响。
2. **K-S 显著性显示**：SPSS 的 K-S(Lilliefors) p 值显示上限为 .200——凡 p ≥ .2 都只显示 ".200"；本工具给出精确值（如 .283/.878），结论一致。
3. **混合设计简单效应**：SPSS EMMEANS 对被试内因子默认输出"多变量检验"（Pillai 等，合并误差）——对应表4上 2 行；若在 SPSS 拆分文件后做重复测量，对应表4下 2 行（单变量假定球形）。两种都是对的，只是 SPSS 打印的是前者的表。
4. **ANCOVA 有两张前提表**：表1 是"斜率同质性"（因子×协变量交互，应不显著）；SPSS 输出里另有一张 "Levene's 同质性变异数检验"——对应表1b（基于全模型残差）。
5. **t 的符号**：独立样本 t 的正负取决于组别顺序（本表按列名字母序，SPSS 按你定义的组1/组2）；|t| 与 p 完全一致。
6. **Huynh-Feldt ε 超过 1**：当 HF ε 估计值 > 1 时按 1 处理（SPSS 亦如此，属正常现象，提示数据球形性较好）；本工具不再打印该提示，GG/HF 校正行的 p 值不受影响。

**非参数事后比较在 SPSS 27 的位置**：旧对话框没有成对比较，用 分析 > 非参数检验 > 独立样本（或相关样本）> 设置 > 成对比较（默认 Bonferroni），输出表与 17/18 模块的事后表对应。

## 前置检查（每个方法统一执行）

任何方法运行前都会先输出两张表：`NN_方法_desc.csv`（所用变量的描述统计：N/M/SD/最值/偏度/峰度，有分组时按组）与 `NN_方法_norm.csv`（Shapiro-Wilk/K-S 正态性检验，参数类方法才有；分类变量改为频数表）。控制台会同步提示正态性与偏度是否达标——先看数据，再谈检验。

## 中英文 Word 结果报告

每次分析完成后自动生成 `stats_report_zh.docx`（中文）与 `stats_report_en.docx`（英文）：每个方法一节，含 三线表、按 \".xxx / < .001\" 格式的 结果句（t/F/χ²/U/H 带自由度与效应量）、关键图（交互图/轮廓图/路径图等）。可以直接作为论文结果部分的初稿，改写变量描述后使用。生成需要 Python（含 python-docx 与 pandas）；未检测到 Python 时跳过，其余输出不受影响。

## 用自己的数据

最省事的路径：运行 `.\run_stats_analysis.ps1`，选 3（或 4 先让向导帮你选方法），按提示输入文件路径和列名。也可以复制 `examples\stats_independent_t_file_template.yaml` 等模板改成自己的列名后用 `-Config` 运行。

注意：
- 因变量列需为数值；分组列可以是文字（如 male/female）或数字编码。
- 重复测量/混合设计要求"宽格式"：每个时间点一列（如 pre, post, followup）。
- 回归的分类自变量请先做 0/1 哑变量（与 SPSS 操作习惯一致）。
- 卡方适合度若有非均匀理论比例，在配置 `analysis.gof_expected_probs` 里按类别顺序给出概率。

## 交互引导都写在哪

- **运行时控制台**：每个方法开头有"什么时候用 / SPSS操作 / 第1步第2步怎么读 / 结果写法 / 常见错误"，跟着屏幕走即可。
- **方法选择向导**（菜单4）：把思维导图里的"实战决策索引"变成问答。
- **00_方法选择决策指南.md**：三问决策树、场景速查表、方差分析三步闭环、非参数对应表、效应量速查。
- **stats_report_zh.md**：全部方法的完整讲解与结果解读（含模拟真值，方便理解"检验结果应该长什么样"）。

## 常见问题

- **R 包安装慢/失败**：首次运行会自动安装 car、emmeans、nortest、pwr 等包；也可换 CRAN 镜像后重试。
- **SPSS 导入 CSV 中文乱码**：数据文件已带 BOM，SPSS 26+ 默认 UTF-8 可正常读；若旧版乱码，在导入向导第 2 步把编码选为"UTF-8"。
- **两组却选了 one_way_anova**：工具会报错提示改用独立样本t（2水平）——按提示换方法即可。
- **控制台中文乱码**：本工具已设置 UTF-8 控制台；若仍乱码，先执行 `chcp 65001` 再运行。
