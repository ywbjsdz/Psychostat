## 0. 一句话结论

三分支的 CTT 与 IRT 输出经**独立复算**后**未发现计算错误**：CTT 61 项、IRT 109 项 L1 闭式复算
全部通过（最大相对偏差 ≤ 6.5e-15，量级为浮点舍入）；用生成时的真值做恢复检验，
IRT 32 项、CTT 4 项全部达到预设判据；与 R 的第二实现 `ltm` 对照，
2PL 与 GRM 的区分度、难度/阈值相关均达 **r = 1.0000**。

本轮**没有改任何统计公式**。改动集中在三类：① 输出口径不一致（CIFA 路径的题名）；
② 一处数值近似精度（IIF 的数值微分从 3 点提到 4 阶）；③ 一处提示写在错误的分支里（小样本警告）。
另有 3 处属于**校对脚本自身**的错误，一并记录在第 7 节。

## 1. 校对范围与方法

三层判据，逐层加强：

| 层 | 名称 | 做法 | 能发现什么 |
|---|---|---|---|
| L1 | 可解析性质复算 | 用教科书闭式公式，从原始数据或参数表**重新算一遍**输出的每一个量 | 公式实现错误、口径漂移、列对应错位 |
| L2 | 已知真值恢复 | 用模拟数据的生成参数（真值文件）检验估计量 | 估计是否正确、方向是否反、标签是否错配 |
| L3 | 独立实现对照 | 换一个**不同作者、不同算法**的 R 包重跑同一模型 | 共同实现错误（闭式复算发现不了的） |

**范围决定**（按你的要求）：**不对 SPSS、也不对 Mplus**。理由：CTT 与 IRT 的权威口径在
`psych` / `lavaan` / `mirt` 的官方文档与教科书闭式中，SPSS 与 Mplus 既非必要参照，
也会引入许可与可比性问题。L3 改用 `ltm`（Rizopoulos, 2006）作为第二实现。

**关键点**：工具的引擎本身就是 `psych`/`lavaan`/`mirt`，所以"用 psych 验证 CTT""用 mirt 验证 IRT"
是同义反复。L1 只依赖**参数表里的 a/d/g** 与**教科书公式**，L3 只依赖**另一个包**，
两者都不经过被测代码。

## 2. IRT：L1 可解析性质复算

**结果：8 个结果目录，PASS = 109，FAIL = 0，SKIP = 13**（SKIP 均为"该路线不适用"，如非 Rasch 目录不查 a≡1）。

覆盖 8 条路线：`2PL / Rasch / 3PL / GRM / 3D-CIFA-GPCM / 2D-CIFA-2PL / 3D-EIFA-GPCM / 2D-EIFA-2PL`。

### 2.1 逐项实测偏差

| 检查 | 复算什么 | 实测最大偏差 | 判定阈值 |
|---|---|---|---|
| I1 | `MDISC = sqrt(Σaⱼ²)` | 0 ～ 3.45e-15 | 相对 1e-8 |
| I2 | `b = −d/MDISC`；GPCM 用台阶 `−(d_k − d_{k−1})/MDISC` | 0 ～ 6.07e-15 | 相对 1e-8 |
| I3 | ICC 用 Samejima(1969)/Muraki(1992)/Birnbaum 闭式，逐题逐 θ 逐类别复算 | 1.44e-15 ～ 4.94e-15 | 绝对 1e-8 |
| I4 | `I(θ) = Σ_k (P_k′)²/P_k`（解析导数） | 2.997e-07 ～ 3.40e-05，均为**峰值的 0.00%** | < 峰值的 1% |
| I5 | `TIF = Σ IIF` | 1.78e-15 ～ 6.52e-15 | 相对 1e-6 |
| I6 | `SE(θ)` 与 `1/sqrt(I(θ))` 的量级（仅单维） | 中位比值 0.860～0.933；r = 0.732～0.999 | 比值∈[0.75,1.25] 且 r ≥ .70 |
| I7a/b/c | 比较表按 BIC 升序；`Selected` 恰一行且等于应选模型 | 8/8 目录一致 | 严格 |
| I8a/b/c | CIFA 载荷矩阵：行数=题目数、每行恰 1 个非零、题名与参数表逐行对齐 | 24/24 与 20/20 | 严格 |
| I9a/b | 缺失审计勾稽（N 的加减、逐题缺失求和） | 逐目录精确相等 | 严格 |
| I10 | 真 Rasch 的 a 必须恒为 1 | 极差 0.000e+00 | 相对 1e-8 |
| I11 | `BH_p = p.adjust(p.S_X2, "BH")` | 5.0e-16 ～ 1.4e-15 | 1e-12 |
| I12 | 8 个目录内所有含 Item 列的输出表题名口径一致 | 全部一致 | 严格 |
| I16 | 经验信度（`mirt::empirical_rxx`）与近似式 `1−mean(SE²)/var(θ)` | 0.0095 ～ 0.1125 | **INFO**，定义不同，不判合格 |

### 2.2 三处判定口径的说明（为什么这样定阈值）

1. **I4 用"占峰值的比例"而非逐点相对差**。工具的 IIF 是 `probtrace()` 的**数值微分**，
   在 `I(θ)≈0` 的两端逐点相对误差必然放大到 >100%，但绝对误差始终很小。
   用峰值占比才能回答"这个近似够不够用"。实测全部路线均 < 峰值的 0.01%。
2. **I6 只对单维模型判定。** 多维下 `mirt` 的 SE 来自**完整信息矩阵**（含维度间交叉信息、
   以及全部题目通过 a_d 对每一维的贡献），而工具的 `tif_data` 是"按主维度分组、其余维度取 0"
   的**条件切面**之和。两者不是同一个量，逐点比大小没有意义，因此多维目录只报告数值。
3. **I16 只报告不判定。** 工具调用 `mirt::empirical_rxx()`（该参数的权威实现），
   校对脚本用的是常见近似式，两者定义不同（实测差 0.0095～0.1125）。

### 3.1 三条必须写进方法学说明的实测结论

1. **3PL 的猜测参数 c 不可用于个体排序。** 实测 r = −0.406、RMSE = 0.139，
   均值无偏（真值 0.168 / 估计 0.171）——即**群体水平可用、题目排序不可用**。
   这是 3PL 的已知弱识别问题，不是实现缺陷；工具的说明文档已据此标注。
   > **2026-09-18 补强（第三方复核提出 `ltm::tpm` 对照后由本机复现）**：
   > `ltm::tpm()` 与工具的 c 相关 **r = 0.9755**（平均差 −0.0011，RMSE 0.0277），
   > 即**两个独立实现互相吻合**；但把两者分别对真值比对，**工具 r = −0.4064、`ltm` r = −0.3638**，
   > 两个实现都恢复不了真值。取值区间更能说明问题：真值 c ∈ [0.087, 0.242]（窄），
   > 工具 [0.012, 0.571]、`ltm` [0.003, 0.580]（宽且与真值无关），
   > `ltm::tpm` 同时报 `Hessian matrix at convergence is not positive definite`——弱识别的典型签名。
   > **结论要点：实现间一致 ≠ 参数可信。** 前者只能说"没有实现缺陷"，
   > 不能据此认为逐题 c 可解读；两条必须一起报告。
2. **EIFA 路线的 θ 不能逐因子比对。** 实测 r ≈ .39～.61，而同样数据走 CIFA 时 r ≈ .93～.94。
   原因是 EIFA 的因子编号由旋转决定，与生成时的因子编号没有对应关系。
   **需要逐因子解释能力估计时必须用 CIFA**（用题目-维度对照表固定归属）。

## 4. IRT：L3 独立实现对照（`ltm` 包）

**结果：在 2 个可对照目录上 PASS = 6，FAIL = 0，SKIP = 0。**
**口径说明**：`ltm` 只覆盖单维 2PL/GRM，因此实际只对 `irt_A`（2PL）与 `irt_B`（GRM）两个目录执行；
若把全部 8 个目录一并传入，另外 6 个目录各产生 1 条 SKIP（`L3_PASS=6 L3_FAIL=0 L3_SKIP=6`）。
记录早期只写了"SKIP = 0"，那是 2 目录调用下的数字，未说明口径（第三方复核指出，已补正）。

`ltm`（Rizopoulos 2006）与 `mirt` 是不同作者、不同估计实现的两个包，参数化在
`IRT.param = TRUE` 下同为**斜率—阈值**形式，可直接比。

| 模型 | 参数 | 相关 | 平均偏差 | RMSE |
|---|---|---|---|---|
| 2PL（irt_A, 20 题） | 区分度 a | **r = 1.0000** | +0.0036 | 0.0048 |
| 2PL（irt_A, 20 题） | 难度 b | **r = 1.0000** | +0.0025 | 0.0034 |
| GRM（irt_B, 15 题） | 区分度 a | **r = 1.0000** | +0.0080 | 0.0087 |
| GRM（irt_B, 4 阈值 × 15 题） | 阈值 b1..b4 | **r = 1.0000** | −0.0070 | 0.0097 |

判据：r ≥ .99 **且** |平均偏差| ≤ .05。实测偏差在 0.008 以内，属于两个包各自优化终止条件
带来的正常差异。这条是三层里最强的一条证据——闭式复算发现不了的"共同实现错误"要靠它。

## 6. 本轮工具侧改动（共 3 处）

**没有改任何统计公式。** 三处改动都可独立验证，且都不影响其它路线的数值。

### 6.1 修复：CIFA 路线的题名口径不一致（输出可用性缺陷）

**现象**：走多维验证性（CIFA）路线时，同一个结果目录里 `icc_data.csv`、`iif_data.csv`、
`item_fit.csv`、`cifa_loading_significance.csv` 写的是内部安全名 `Item1`、`Item2`…，
而 `item_parameters.csv`、`cifa_loading_matrix.csv`、`item_overview.csv` 等写的是用户原始题名
`Item01`、`Item02`…。后果是**同一批输出无法按 `Item` 直接 join**，做题名筛选或批量合并时会静默丢题。

**根因**：CIFA 路线为了让 mirt 的模型语法合法，内部把题名换成 `Item1…`（第 149–160 行的
`safe_items`），参数表在写出前用 `cifa_to_orig_item()` 翻了回去（第 209、244 行），
但绘图函数与题目拟合表漏了这一步：

- `plot_irt_curves()` 用 `names(x)[i]`（= 安全名）作标签 → `icc_data`/`iif_data`/`tif_data` 全错；
- `extract_cifa_significance()` 的输出列直接用内部名；
- `item_fit` 的 `item` 列来自 mirt，同样是安全名。

**修法**（`scripts/irt_generic_pipeline.R`，4 个位置）：
绘图标签改用已翻回原名的 `pars$Item`；另两处套用同一个 `cifa_to_orig_item()`。
该函数在非 CIFA 路线是恒等映射，因此**其余路线输出逐字节不变**。

**顺带修正**：`item_fit.csv` 的 `Item` 列原本是 `rownames()`，而 mirt 的 `itemfit()` 行名是行号
（"1"、"2"…），这一列从来不是题目名。现改为与 `item` 列同为原始题名（列仍然存在，
不动输出结构）。此列此前无人使用，改后不影响任何消费方。

### 6.2 改进：IIF 的数值微分从 3 点格式提到 4 阶

`mirt::probtrace()` 不提供解析导数（已核对 `args()`，只有 `x, Theta` 两个形参），
所以题目信息量只能用 θ 网格上的数值微分。原实现是 3 点格式（内部中心差分、两端单侧差分），
截断误差 O(h²)，实测相对解析解最大偏到**峰值的 2.7%**。

改为 4 阶格式（内部 5 点中心差分、两端 4 阶单侧差分，`h = 0.05`）后的实测（判据 = 最大绝对差 < 峰值的 1%）：

| 模型（目录） | 3 点格式 | 4 阶格式（现在） |
|---|---|---|
| 2PL | 最大偏到峰值的 **2.7%**（换格式前的实测值） | 1.92e-05 = 峰值的 **0.00%** |
| Rasch | — | 3.00e-07 = 峰值的 **0.00%** |
| 3PL | — | 1.41e-05 = 峰值的 **0.00%** |
| GRM | — | 6.84e-06 = 峰值的 **0.00%** |
| 3D-CIFA-GPCM | — | 3.40e-05 = 峰值的 **0.00%** |
| 2D-CIFA-2PL | — | 6.92e-06 = 峰值的 **0.00%** |
| 3D-EIFA-GPCM | — | 2.87e-05 = 峰值的 **0.00%** |
| 2D-EIFA-2PL | — | 7.75e-06 = 峰值的 **0.00%** |

这属于"同一公式的更精确数值实现"，不是公式改动。

### 6.3 修复：小样本警告写在了错误的分支里

`irt_preflight.R` 里那条"样本量仅 N：IRT 参数估计极不稳定"的警告，被写在了
`if (requested_model == "mirt")` **内部**——也就是只有多维路线才会提示，
而单维 2PL/GRM 的样本量敏感性并不更低（2PL 每题还要多估一个区分度）。
注释写的是"n=30 跑 2PL/GRM 会毫无提示地出结果"，代码却没做到。

修法：把两条通用小样本警告移到 `mirt` 分支**之外**，对全部 IRT 路线生效；
`mirt` 分支内保留它自己的"低于 200"提示。实测边界行为：

| 用例 | n | 模型 | 计分 | 修前 | 修后 |
|---|---|---|---|---|---|
| `e2e_irt_small_n` | 40 | 2PL | 二分 | 无提示 | **warning「样本量仅 40…」** |
| 新造 | 80 | 2PL | 二分 | 无提示 | ok（不提示） |
| 新造 | 80 | GRM | 多级 | 无提示 | **warning「样本量 80 且模型参数较多…」** |
| 新造 | 400 | GRM | 多级 | ok | ok |
| 新造 | 90 | 3PL | 多级 | — | fatal（多级数据本就不能拟合 3PL，先被拦下） |

## 7. 校对脚本自身的缺陷（诚实记录）

校对脚本也会错。本轮它有 5 处错误，全部由"工具与闭式对不上"触发、再逐一定位到脚本自身——
这一步很关键，否则会把**自己的 bug 当成工具的 bug 报上去**。

| # | 脚本 | 错误 | 后果 | 定位方式 |
|---|---|---|---|---|
| 1 | `verify_l1_irt.R` | GRM 的 `P_k` 少算了尾类：写成 `sv[-K] − sv[-1]`，漏掉隐含的 `S_{K+1} = 0` | **虚报 GRM 全部 15 题 IIF 失败**（偏差 191% 峰值） | 工具值与"我对同一 P_k 做 4 阶差分"吻合到 **1.4e-14**，证明工具无误、脚本有误 |
| 2 | 同上 | 一度改用"Σ[S_k′]²/(S_k(1−S_k))"这个**并不成立**的所谓等价式（GRM 的 P_k 是相邻累积函数之差，没有这种简化） | 该式系统性偏大 ~2 倍 | 与直接式对拍，两者互相矛盾即说明记忆有误 |
| 3 | 同上 | 用字符串相等匹配题名，CIFA 目录下 `Item1…Item9` 匹配不到 `Item01…Item09`，且失配时 `next` 静默跳过 | **I3 在 CIFA 目录下是"部分假通过"**（只验了 10–20 题） | 加 I12（题名口径一致性）后暴露 |

### 12.3 值得记录的复核方法

第三轮在方法上有两处做得比前两轮更好，可作为后续复核的模板：

1. **先标定、再比对**。它没有直接去比二维参数，而是先用**单维 GPCM**（同一模型、两引擎、秒级）

2. **量尺锚定**。二维比较前用零截距最小二乘把两引擎的潜在量尺对齐
   （`a_mirt = 0.9563302 × a_TAM`），避免把**识别尺度差异**误判成**产品参数差异**。
