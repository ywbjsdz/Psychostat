## 第 0 章 关于本手册

### 0.1 Psychostat 能做什么

| 分支 | 你拿它做什么 | 核心内容 |
|---|---|---|
| **心理统计** | 统计课作业、毕业论文的数据分析部分 | 21 个方法：描述统计、前提检验、三种 t 检验、四种方差分析、ANCOVA、相关/偏相关、回归、两类卡方、四种非参数检验、中介、调节、功效分析 |
| **CTT**（经典测量理论） | 编制/修订量表，检验信度与效度 | 数据清洗 → 项目分析 → 信度与效度 → EFA（探索）或 CFA（验证） |
| **IRT**（项目反应理论） | 测验/量表更精细的题目分析、能力估计 | Rasch / 2PL / 3PL / GRM / 多维 IRT（探索 EIFA、验证 CIFA） |

### 0.2 它**不**做什么（重要）

- 不做因果推断：中介/调节只是**统计**中介/调节，因果要靠设计（随机化、纵向追踪）。
- 不做临床、选拔、高风险决策（如心理病理诊断、人事筛选）。
- 不做复杂设计：多层线性模型（HLM）、结构方程全模型、潜变量增长模型、网络分析等需用 Mplus/lavaan/其它专用工具。
- 不替代你的判断：**所有自动提示（建议删题、模型推荐、显著性标记）都是决策辅助**，不是结论。

### 0.3 它和你听说过的软件是什么关系

- 与 **SPSS** 对照：心理统计分支的统计口径按 SPSS 27 默认设置实现（Type III 平方和、均值中心 Levene、Mauchly+GG/HF、LSD/Tukey/Bonferroni 等），每个模块都会输出与 SPSS 一一对应的表格，方便你课上学 SPSS、课下用它复现。
- 与 **R 包**的关系：CTT 分支内核是 `psych` + `lavaan`，IRT 分支内核是 `mirt`。也就是说，Psychostat 并没有"重新发明"统计，它做的是：**参数配置 + 数据体检 + 表格整理 + 教学解释 + 结果成稿**。

## 第 1 章 10 分钟上手

### 1.1 三种入口，按需要选

| 入口 | 适合谁 | 怎么用 |
|---|---|---|
| **图形界面（推荐）** | 不熟命令行 | 双击 `启动Psychostat界面.bat` → 左边选分支，跟着步骤走，所有文件/变量都是选择框 |
| **命令行启动器** | 需要批量、重复运行 | 双击 `启动心理统计.bat` / `启动量表编制_CTT.bat` / `启动项目反应理论_IRT.bat`，或运行 `.\run_stats_analysis.ps1 -Method independent_t -Data .\my.csv` |

### 1.2 环境和依赖

| 依赖 | 是否必须 | 说明 |
|---|---|---|
| Windows 10/11 + PowerShell 5.1+ | 必须 | 本工具仅支持 Windows；`.bat` 是 Windows 专用脚本，macOS / Linux 无法运行 |
| **R** | 必须 | 首次运行会提示是否自动下载安装（约 100 MB，装到 `D:\R` 或用户目录，无需管理员权限） |
| **Python** | 可选 | 仅用于生成 Word 结果报告；没有 Python 时 CSV/图/Markdown 报告照常产出 |
| 网络 | 仅首次 | 自动安装缺失的 R 包（国内镜像优先、失败自动换源） |

> 装 R 包时建议优先装到 D 盘（启动器默认优先 D 盘）。首次运行会自动安装缺失的 R 包，**国内网络下可能需要几十分钟**（psych/lavaan/mirt 及其依赖合计数百 MB）；工具逐包显示进度并自动换源，中断后重跑会接着装而不是从头再来。

### 1.3 结果放在哪

每次运行都会新建一个**带时间戳**的结果目录，**不会覆盖历史结果**：

```
outputs\
└─ <你的标签>_<分支>_<日期>_<时间>\
   ├─ NN_方法_data.csv           ← 本次分析的原始/模拟数据（可直接导入 SPSS 复现）
   ├─ NN_方法_*.csv              ← 各类结果表（描述统计、检验结果、事后比较……）
   ├─ *.png                      ← 300 dpi 图（箱线图、交互图、路径图、ICC/IIF/TIF……）
   ├─ stats_report_zh.md         ← 中文教学报告（什么时候用→怎么读→结果写法）
   ├─ *_report_zh.docx       ← 中文 Word 结果报告初稿
   ├─ *_report_en.docx       ← 英文版
   ├─ config_snapshot.*          ← 本次配置快照（可复制为下次调用参数）
   ├─ run_log.txt                ← 运行日志（含所用包的版本）
   └─ run_manifest.json          ← 机器可读的可复现清单（时间/R 版本/包版本/种子）
```

### 1.4 出错时的三步排查

1. **看窗口最后几行**：启动器会把 R 的英文报错翻译成中文提示（例如"找不到列名""某列没有变异"）。
2. **看 `run_log.txt`**：完整日志，含包版本。
3. **加 `-Verbose`** 重新运行一次，可看到 R/Python 的原始诊断输出。

### 1.5 不用了怎么彻底清理（留给"只用一次"的场景）

Psychostat 在你的电脑上只补充安装两类东西：**R 本体**（若你没有）与**少量 R 包**、**Python 依赖**（若你没有 Python，或缺 pandas/python-docx）。
为了让你事后能删干净，工具**把新增的包装进专属目录**，并把位置记录在一份安装清单里：

| 内容 | 默认位置（按优先级） | 说明 |
|---|---|---|
| 本工具新增的 R 包 | `D:\Psychostat-R-Library` → R 安装目录旁的 `Psychostat-R-Library` → `C:\Psychostat-R-Library` → `%LOCALAPPDATA%\Psychostat\Psychostat-R-Library` | **不与你已有的 R 包混在一起**（不动系统安装目录里的包） |
| 本工具新增的 Python 依赖 | `<Python目录>\Psychostat-Python-User` → `C:\Psychostat-Python-User` → `%LOCALAPPDATA%\Psychostat\Psychostat-Python-User` | pandas / python-docx / lxml |
| 临时目录重定向 | `C:\PsychostatTemp` | 仅当你的 TEMP 路径含中文时启用（例如中文用户名） |
| 安装清单 | `%LOCALAPPDATA%\Psychostat\install_manifest.json` | 记录装了什么、装在哪、什么时候装；**不随项目文件夹拷走**（它是这台机器的信息） |

**清理方式（三种任选，都不需要记命令）：**

| 方式 | 怎么做 | 适合谁 |
|---|---|---|
| ① **界面按钮（最省事，推荐）** | 双击 `启动Psychostat界面.bat` → 左侧点 **「清理已安装环境」** → 弹出**可滚动**的预览窗口，看清楚后：想清理就点「清理上面这些目录」，只想看看就点「什么都不做（关闭）」；完成后会告诉你删了什么、释放了多少 | 完全不想碰命令的人 |

- ❌ 不删除**已存在的** R / Python 本体 —— 你可能还在用 RStudio 或别的脚本依赖它们；脚本只会告诉你"当初是不是我们装的"以及怎么卸载。

- ❌ 不删除你的 `outputs\`（分析结果）与 `data\`（你的数据）—— 只在预览里列出体积提醒你。
- ✅ 只删除**目录名在固定白名单内**的专属目录；即使清单被改动指向别处，也会拒绝执行（显示 `[拒绝]`）。

## 第 2 章 数据准备：90% 的报错都出在这里

### 2.1 通用规则（三个分支都适用）

| 规则 | 说明 |
|---|---|
| **一行 = 一名被试** | 不要出现同一人的多行（纵向数据要么宽格式、要么先自己整理） |
| **一列 = 一个变量** | 量表题就是"一题一列"，不要预先算好总分再当变量（心理统计分支要的是原始分或已明确说明的合成分） |
| **支持格式** | `.csv`（推荐 UTF-8）、`.xlsx` / `.xls`、SPSS `.sav` |
| **列名** | 中文列名可用；但**不要带前后空格**，同名不要重复。CSV 建议 UTF-8 with BOM，这样 Excel/SPSS 打开不乱码 |
| **缺失值写法** | 空单元格、`NA`、`.`（点）都会被识别为缺失；**不要写 999/-1 之类的"哨兵值"**，它们会被当成真实分数 |
| **不要包含** | 姓名、学号、电话、邮箱、时间戳自动列（工具会自动识别并拒绝，但最好先删掉） |

### 2.2 心理统计分支：变量角色

在 GUI 里，选完数据文件后会自动读取列名，然后让你用下拉框指定每个方法的**变量角色**：

- `dv`：因变量（被解释的连续变量）
- `group` / `factor_a` / `factor_b`：分组变量或自变量因子
- `within`：重复测量的各时间点列（**按时间顺序**勾选）
- `covariate`：协变量（ANCOVA 用）
- `predictors`：回归的自变量列
- `x` / `m` / `y`：中介模型的三个变量
- `interaction_x` / `interaction_z` / `interaction_dv`：调节模型的 X、调节变量 Z、因变量 Y
- `mu`：单样本 t 检验的检验值（与哪个总体常模比较；留空按 50）

**同一个变量名在多个方法里只设置一次**（例如 `dv` 在描述统计与独立样本 t 里共用）。

### 2.3 CTT 分支：题目列的规则

- 题目列必须是**数值计分**列（1–5、0–3 等）。文本型（"非常同意"）或**因子型**列会被明确拒绝——因为那样会把"男/女"编码成 1/2 当成分数算。
- 自动识别规则：数值列中**取值在 2–12 类之间**且不是常见的 ID/人口学/合成分命名（`id`、`gender`、`age`、`total`、`score`、`group`、`time` 等）才会被当成题目。**一旦自动识别撞上疑似非题目列，工具会直接报错让你手工指定**，不会默默算错。
- 反向计分题：在配置里写 `reverse_items: [Item5]`，并设置 `scale_maximum`（如 5 点量表填 5）。工具按 `k + 1 − 原始分` 转换，且**在插补缺失之前**完成转换，保证后续所有统计方向一致。
- 注意检验题（如"请在本题选 3"）：写 `attention_item` + `attention_correct_value`，答错者默认**删除**。
- 反应时列：写 `response_time_column` + `minimum_response_seconds`，过快作答默认**删除**。

### 2.4 IRT 分支：比 CTT 更严格

- 题目必须是**整数计分**（0/1 或 1–5）。小数（如 3.5）会被拒绝。
- **至少 3 个题目**；建议每维至少 4–6 题。
- 样本量：二分模型建议 ≥ 200–500；GRM/MIRT 建议 ≥ 500（工具在 MIRT 样本 < 200 时给警告）。
- 运行前会先做**数据体检**（`irt_preflight.R`），检查：整题全缺失、零方差题、缺失率（总体 >10% 提醒、单题 >20% 提醒）、极少使用的反应类别、二分类/多级计分与所选模型是否匹配。**致命问题会挡住分析**（如"多级数据却选了 2PL"）。

## 第 3 章 心理统计分支：21 个模块的方法注释

### 3.0 每个模块的固定结构

运行任一模块前，工具都会先做**第 0 步前置检查**：输出所用变量的描述统计（N、M、SD、min、max、偏度、峰度），参数类方法再附**正态性检验**（Shapiro-Wilk 优先，样本量超出 3–5000 时自动跳过；同时给出 Kolmogorov-Smirnov 的 Lilliefors 版本）。

> **SPSS 对照小知识**：SPSS"探索"里的 K-S 显著性显示上限是 `.200`——凡是 p ≥ .2 都只显示 `.200`。本工具给出精确渐近值（如 .878），结论一致。偏度/峰度用 SPSS 的 g1/g2 口径与教科书无关的"总体校正"公式，可与 SPSS 逐位对照。

**族别提示**：回归/相关族（相关、回归、中介、调节）在 S-W 显著时不会提示你"改用非参数"——因为这些方法的重点前提是**残差**正态性与影响点，不是自变量本身的分布；工具已另外输出 VIF、Durbin-Watson 与残差诊断。

---

### 3.1 描述统计（`descriptives`）

- **什么时候用**：任何分析的第一步。报告样本的集中趋势与离散程度，检查是否有异常值或错误编码。
- **算什么**：N、M、SD、min、max、偏度 g1、峰度 g2，以及标准化分数（Z）。
- **怎么读**：偏度 |g1| ≥ 1 提示明显偏态（工具会主动提示）；标准差为 0 说明该列没有变异（无法分析）。
- **结果句模板**：*M* = 45.2, *SD* = 11.8, 偏度 = 0.32。
- **常见错误**：把分类变量当连续变量算均值（如"性别均值 1.5"没有意义）。

### 3.2 正态性与方差齐性（`normality`）

- **什么时候用**：t 检验/方差分析之前；或审稿人要求报告前提检验。
- **算什么**：Shapiro-Wilk（n ≤ 5000）、K-S（Lilliefors）、按组分的偏度/峰度；Levene 方差齐性检验。
- **怎么读**：S-W *p* > .05 → 未检出偏离正态。**注意**：大样本下 S-W 极其敏感，轻微偏离就显著；这时更应看偏度/峰度绝对值与直方图/QQ 图，而不是机械地改用非参数检验。
- **常见错误**：把"正态性检验显著"当成"必须用非参数检验"。正确做法是看偏离程度 + 方法稳健性（t 检验/ANOVA 对中等偏离相当稳健，尤其 n 较大时）。

### 3.3 单样本 t 检验（`one_sample_t`）

- **什么时候用**：把一样本的均值与已知总体值/常模比较（如"本班焦虑分是否高于全国常模 μ=50"）。
- **统计量**：$t = \frac{\bar{X} - \mu}{s/\sqrt{n}}$，df = n − 1。
- **效应量**：Cohen's *d* = (M − μ)/SD。
- **常见错误**：忘记设置检验值 μ（GUI 里"检验值 μ"留空则按 50 计算，必须改成你的常模值）。

### 3.4 独立样本 t 检验（`independent_t`）

- **什么时候用**：两组**不同的人**比较一个连续变量（男/女、实验/控制）。
- **工具输出两行**：假定方差相等（合并方差 t）与不假定方差相等（Welch t），并按 Levene 结果**自动提示该读哪一行**——这与 SPSS 的做法一致：Levene *p* > .05 读上一行，*p* ≤ .05 读 Welch 行。
- **效应量**：Cohen's *d*（合并 SD），另附 Hedges' *g*（小样本校正）。
- **常见错误**：只看"显著性"不看方向（谁比谁大）；两组样本量差异巨大时仍用合并方差 t。

### 3.5 配对样本 t 检验（`paired_t`）

- **什么时候用**：同一批人前后测、配对设计。
- **统计量**：对**差值**做单样本 t 检验。
- **方向约定**：本工具按"后测 − 前测"计算，因此正值表示后测更高。
- **常见错误**：把两组独立数据误用配对 t（或反之）；忽略差值的正态性（差值明显偏态时用 Wilcoxon 符号秩）。

### 3.6 单因素方差分析（`one_way_anova`）

- **什么时候用**：≥3 组独立样本比一个连续变量。
- **算什么**：Type III 平方和的 ANOVA 表、`partial η²`、Levene、事后比较（LSD / Tukey / Bonferroni 三套同时给）、稳健检验（Welch ANOVA、Brown-Forsythe）。
- **事后比较怎么选**：LSD 不校正（探索性、组数少时用，容易假阳性）；Tukey 控制全部两两比较的族错误率（最常用）；Bonferroni 最保守。
- **效应量**：$\eta^2_p = \frac{SS_{效应}}{SS_{效应}+SS_{误差}}$，.01/.06/.14 = 小/中/大。
- **常见错误**：组数 ≥3 却只做多次两两 t 检验（假阳性膨胀）；F 显著后不做事后比较就下结论；把 LSD 当成默认。

### 3.7 两因素方差分析（`two_way_anova`）

- **什么时候用**：两个自变量的被试间设计（如 教学法 3 × 动机 2）。
- **三步闭环**（工具会按这个顺序引导你）：① 看主效应 → ② 看交互（**交互显著则主效应失去直接解释意义**）→ ③ 做简单效应。
- **简单效应怎么给的**：用 `emmeans` 从**全模型**估计（保留原模型误差项），对应 SPSS"一般线性模型 → EM 均值 → 简单效应"；这一点比"拆分文件后做单因素 ANOVA"更准确，因为非均衡设计的误差项不变。同时给出 A 在各 B 水平、B 在各 A 水平两个方向的成对比较（Bonferroni）。
- **常见错误**：交互显著还去解释主效应；用"拆分文件"法做简单效应（误差项被换掉，df 和 p 都会不对）。

### 3.8 重复测量方差分析（`rm_anova`）

- **什么时候用**：同一批人在 ≥3 个时间点/条件上测量。
- **球形性**：Mauchly 检验 + Greenhouse-Geisser（GG）与 Huynh-Feldt（HF）校正；HF ε > 1 按 1 处理（与 SPSS 约定相同）。
- **怎么读**：Mauchly *p* < .05 → 球形性违反 → 报告 GG（ε < .75 时）或 HF（ε > .75 时）校正后的 p；同时报告 ε。
- **常见错误**：不报告 ε 与校正 p；用配对 t 检验反复比较 4 个时间点（多重比较未校正）。

### 3.9 混合设计方差分析（`mixed_anova`）

- **什么时候用**：一组被试间因子 + 一组被试内因子（干预组/对照组 × 前测/后测/随访）。
- **工具给两套简单效应**：SPSS 对被试内因子的简单效应默认打印**多变量检验**（Pillai 等 4 行）；若在 SPSS 里"拆分文件"后做重复测量，则得到"单变量假定球形"版。两套都输出并说明对应关系。
- **常见错误**：混淆两套口径；忽略交互就只解释组间差异。

### 3.10 协方差分析（`ancova`）

- **什么时候用**：控制一个连续协变量（如前测成绩、智商）后比较组间差异。
- **前提（工具会专门输出）**：
  1. **回归斜率同质性**：组 × 协变量交互不显著 → 才能用统一斜率调整。**工具会明确提醒"这不是 Levene 检验"，虽然 SPSS 输出里两者位置相近**。
  2. 误差方差齐性（基于模型残差的 Levene）。
- **结果怎么读**：看**调整后均值**（用 `emmeans` 在协变量均值处估计）与组间 F。
- **常见错误**：跳过斜率同质性直接读组间差异；把 ANCOVA 当成"消除一切混淆"的魔法（它只调整已测量的协变量）。

### 3.11 相关与偏相关（`correlation`）

- **什么时候用**：两个连续变量的关联强度（Pearson），或等级/偏态数据（Spearman）；控制第三变量后用偏相关。
- **数据准备注意**：工作区里那两个"事实修正"文件（`tests/data/test_*.csv`）与其它内容文件只用于内部回归测试，**不属于你的分析数据**——做验证时不要混用。请使用 `outputs\...\NN_方法_data.csv` 或你自己的数据。
- **怎么读**：|r| = .10/.30/.50 → 小/中/大；报告 r、p、n，以及在"要下因果结论"时提醒读者**相关不等于因果**。
- **常见错误**：把 r 的显著性当成"关系很强"（大样本下 r = .1 也能显著）；偏相关用错控制变量（会引入过度控制偏倚）。

### 3.12 多元线性回归（`regression`）

- **什么时候用**：用多个自变量预测一个连续因变量；或控制多个变量后看某个自变量的独立贡献。
- **算什么**：模型汇总（R²、调整 R²、标准误、Durbin-Watson）、ANOVA 表、系数表（B、SE、β、t、p）、共线性诊断（容差、VIF）、残差诊断（含标准化残差图）。
- **阈值**：VIF < 5（严格 < 2.5）、容差 > 0.2；Durbin-Watson ≈ 2 表示残差独立（1.5–2.5 一般可接受）。
- **报告要点**：写清每个 B 的**单位**（"学习时间每增加 1 小时，成绩提高 0.5 分"）；报告调整后 R² 而不是只报 R²。
- **常见错误**：R² 高但系数都不显著 → 先查共线性；把 Beta 当因果系数；分类自变量不做哑变量（工具会提醒）。

### 3.13 卡方适合度检验（`chi_square_gof`）

- **什么时候用**：一个分类变量的实际分布是否与理论比例一致（如四种学习风格是否均匀分布）。
- **统计量**：$\chi^2 = \sum \frac{(O-E)^2}{E}$，df = 类别数 − 1。
- **效应量**：Cohen's *w*。
- **常见错误**：期望频数 < 5 的类别过多时仍用卡方（应考虑合并类别或精确检验）。

### 3.14 卡方独立性检验（`chi_square_independence`）

- **什么时候用**：两个分类变量是否关联（性别 × 择业偏好）。
- **工具输出**：Pearson 卡方（**不做 Yates 校正**，与 SPSS 的 Pearson 行一致）与 2×2 情形下的**连续性校正**行，另附 Cramér's *V*。
- **怎么读**：看"Pearson 卡方"的 p；2×2 表若期望频数偏小，参考"连续性校正"行或 Fisher 精确检验（SPSS 中手动）。
- **效应量**：$\phi$ / Cramér's *V* = $\sqrt{\chi^2/(n\cdot\min(r-1,c-1))}$，.10/.30/.50。
- **常见错误**：把".000"读成"完全独立"；用卡方检验 2×2 表却不报告 n。

### 3.15 Mann-Whitney U 检验（`mann_whitney`）

- **什么时候用**：两组独立样本，但数据是等级/明显偏态/有极端值（独立样本 t 的非参数替代）。
- **工具输出**：U（取较小值，与 SPSS 一致）、Wilcoxon W、**含结点校正的渐近 Z**、p（渐近/精确）、秩均值、效应量 *r* = |Z|/√N。
- **常见错误**：以为它比 t 检验"更安全"（它在正态数据上功效更低）；不报告效应量（只看 p）。

### 3.16 Wilcoxon 符号秩检验（`wilcoxon_signed`）

- **什么时候用**：配对/前后测的等级或偏态数据（配对 t 的非参数替代）。
- **工具输出**：V/统计量、含结点校正的 Z、p、正/负秩和、效应量 r。
- **常见错误**：与 Mann-Whitney 混用（一个是相关样本、一个是独立样本）；忽略差值为 0 的被试（本工具按 SPSS 的零差处理约定）。

### 3.17 Kruskal-Wallis H 检验（`kruskal_wallis`）

- **什么时候用**：≥3 组独立样本的非参数比较（单因素 ANOVA 的非参数替代）。
- **工具输出**：H、df、p、各组平均秩、效应量 $\eta^2_H$。
- **常见错误**：H 显著后不做两两比较（工具会提示后续步骤）；样本量小、组间方差悬殊时读 H 要谨慎。

### 3.18 Friedman 检验（`friedman`）

- **什么时候用**：≥3 个相关条件/时间点上的等级或偏态数据（重复测量 ANOVA 的非参数替代）。
- **工具输出**：Friedman χ²_F、df、p、**被试内平均秩**（与 SPSS 的"平均秩"口径一致）、Kendall's W。
- **常见错误**：把它当成重复测量 ANOVA 的"更保险版本"（球形性不满足时它更合适，但正态且球形可接受时 ANOVA 更灵敏）。

### 3.19 中介效应（`mediation`，PROCESS Model 4）

- **什么时候用**：回答"X 如何通过 M 影响 Y"。
- **模型**：总效应 c（Y~X）／a（M~X）／b（Y~M|X）／直接效应 c′（Y~X|M）／间接效应 ab。
- **区间估计**：**Bootstrap 5000 次百分位法 95% CI**（与 PROCESS 的 BootLLCI/BootULCI 对应），并附 Sobel 检验供参考。
- **怎么读**：CI 不含 0 → 间接效应成立；随后报告 ab、CI、c′ 与 ab/c 的占比。
- **重要提醒**：横断面数据的"中介"是**统计**中介；"完全/部分中介"的二分说法近年受到批评，建议同时报告 ab、CI 与占比，并谨慎表述因果。建议 N ≥ 200。
- **常见错误**：只做三步回归、不看 Bootstrap CI；用横断面数据写"X 通过 M 导致 Y"。

### 3.20 调节效应（`moderation`，PROCESS Model 1）

- **什么时候用**：回答"X 的效应在什么条件下更强"。
- **模型**：先把 X、Z 中心化，再构造乘积项：$Y = b_0 + b_1X_c + b_2Z_c + b_3X_cZ_c$；$b_3$ 显著即存在调节。
- **简单斜率**：给定 Z 的取值，X 的斜率 = $b_1 + b_3Z$；工具在 Z = 均值、±1 SD 处给出斜率、SE、t、p，并画交互图。
- **常见错误**：不中心化就直接乘积（共线性、解释困难）；交互显著后把主效应当成"普遍效应"；把调节与中介混为一谈（一个是"何时更强"，一个是"如何起作用"）。

### 3.21 统计功效与样本量（`power`）

- **什么时候用**：**开题/设计阶段**（事前分析）算需要多少被试；或已有样本做**敏感性分析**（能检测到多大效应）。
- **工具输出**：独立样本 t（d = .2/.5/.8 × power = .80/.90）、单因素 ANOVA（f = .25, k = 3）、Pearson 相关（r = .30）、多元回归（f² = .15, 3 个预测变量）的样本量表。
- **关键数字**（记住这几个）：两独立样本、*d* = 0.2、power = .80 → **每组约 394 人（总约 788）**；*d* = 0.5 → 每组 64；*d* = 0.8 → 每组 26。单样本/配对设计约是上述的一半（d = 0.2 → 约 199 人）。
- **常见错误**：事后再算 observed power 并据此解释不显著结果（这是循环论证，期刊不接受）；把 Cohen 的阈值当成研究领域的真实效应量（应查 meta 分析或预实验）。

## 第 4 章 统计概念补课：新手最容易搞错的 12 件事

1. **p 值不是"效应为真的概率"**：它是在"零假设成立"的假设下，观察到当前或更极端数据的概率。p < .05 只说"数据与原假设不太相容"。
2. **显著 ≠ 效应大**：n 一大，r = .10 也显著。必须同时报告**效应量**及其 CI。
3. **不显著 ≠ 无效应**：可能是样本不足。请报告效应量与 CI，而不是"p > .05，所以无差异"。
4. **"p = .000"是错的写法**：SPSS 的 `.000` 意思是"小于 .001"，结果句应写 *p* < .001（本工具的 结果报告已按此格式）。
5. **正态性检验不是投票**：S-W 显著只说明"检出偏离"，要结合偏度/峰度和方法稳健性判断。
6. **多重比较必须处理**：做 3 组两两比较（3 次 t 检验）时假阳性率约 14%，应使用 Tukey/Bonferroni 等校正。
7. **相关不等于因果**：无论 r 多大。
8. **中介不等于机制**：统计中介只是"数据与中介模型相容"，横断面设计下无法排除反向与第三变量解释。
9. **信度不是"越高越好"**：α = .95 往往意味着题目高度重复（冗余）。α 是信度下限，且假设题目 τ 等价。
10. **因子分析不是"整理题目"的自动化工具**：用同一批数据挑题目、再报信度，会系统性高估（本工具的 EFA 默认"只标注不删题"正是为此）。
11. **球形性/方差齐性影响的是 p 值口径**，不是"结果对不对"；违反时用校正版（GG/HF、Welch）即可，不必放弃方法。
12. **报告要能复现**：写清软件版本、随机种子、缺失值处理、删题标准。Psychostat 的 `run_manifest.json` 与 `config_snapshot.*` 就是干这个用的。

## 第 5 章 CTT 分支：量表编制与验证

### 5.1 三条互斥路线

| 路线 (`analysis.goal`) | 做什么 | 什么时候用 |
|---|---|---|
| `quality` | 清洗 + 项目分析 + 信度 + 效度证据 | 只要量表质量报告（不关心因子结构） |
| `efa` | 上面 + **探索性**因子分析 | 新编量表、不知道结构、想探索维度 |
| `cfa` | 上面 + **验证性**因子分析（需题目-维度对照表） | 已有理论结构，想在**新样本**上验证 |

> **为什么互斥**：用同一批数据先做 EFA 得出结构、再用同一批数据做 CFA 验证，等于"用答案考自己"，拟合指标会严重乐观。工具强制分开路线（旧的"EFA→CFA 同数据"用法已被降级为警告并只跑 EFA），并在运行日志中写明"验证 EFA 得出的结构需要独立样本"。

### 5.2 数据清洗（每一步都可审计）

工具输出 `01_cleaning_summary.csv`（总体情况）与 `01_case_cleaning_audit.csv`（**每一名被试**的逐条标记），以及清洗后的题目矩阵 `01_cleaned_items.csv`。

| 规则 | 默认行为 | 配置项 |
|---|---|---|
| 反向计分 | 按 `k + 1 − 原始分` 转换（**在插补之前**） | `cleaning.reverse_items`、`scale_maximum` |
| 单题缺失率 < 5% | 用**该题中位数**插补 | 固定规则 |
| 单题缺失率 5%–20% | 按配置：`stop`（默认，报错让你决定）/ `listwise`（删人）/ `median_impute`（插补） | `missing_5_to_20` |
| 单题缺失率 > 20% | 删除该被试 | 固定规则 |
| 注意检验失败 | 删除 | `attention_item`、`attention_correct_value` |
| 作答过快 | 删除 | `response_time_column`、`minimum_response_seconds` |
| 直线作答（所有题同一选项且 ≥3 题） | 默认**标记**不删 | `straightline_action: flag\|remove` |
| 极端值（总分 \|z\| > 3 或 1.5 IQR 之外） | 默认**标记**不删 | `extreme_action: flag\|remove` |
| 清洗后不足 30 人 | 直接报错停止 | 固定规则 |

> **研究者提示**：插补/删除规则必须在论文的"数据处理"部分写清楚。工具的审计表就是给你写这段用的。

### 5.3 项目分析（`02_item_analysis.csv`）

| 指标 | 含义 | 常用判定 |
|---|---|---|
| **CR（决断值）** | 把总分排序，取**高分组 27%** 与**低分组 27%**，对每题做独立样本 t 检验（工具用 Welch t，不假定方差齐性） | CR *t* > 3.0 且 *p* < .05 |
| **CITC** | 校正的题总相关：该题与"总分减去该题"的相关（`r.drop`） | > .30 |
| **retain_recommendation** | 同时满足上述两条 | TRUE/FALSE |

> **为什么用 27%**：极端组法（决断值法）来自经典测验理论的传统，27% 是使两组差异最大化的近似最优比例。**注意**：CR 与 CITC 都是"该题与总分的关系"，如果量表本身是多维的，题目可能因为维度不同而 CITC 偏低——这时应分维度计算，而不是直接删题。

### 5.4 信度（`03_reliability.csv`、`03_alpha_if_deleted.csv`）

- **Cronbach's α**：$\alpha = \frac{k}{k-1}\left(1 - \frac{\sum \sigma_i^2}{\sigma_{total}^2}\right)$，其中 k 为题目数，$\sigma_i^2$ 为各题方差。默认判定阈值 **α > .70**（工具直接给出 `acceptable_alpha_gt_70`）。
- **删除该题后的 α**（`alpha_if_deleted`）：只有当删除后 α **上升超过 .05** 才标记 `delete_recommendation = TRUE`。
- **EFA 路线**：会额外给出**按探索出的维度**计算的分量表 α；CFA 路线则按你提供的对照表计算。
  > ⚠️ 注意：EFA 路线的维度是**从同一批数据里探索出来的**，据此算出的分量表 α 会偏乐观（循环性）。如果要报告分量表信度，最好在独立样本上验证结构之后再算。
- **本工具已提供**：McDonald's ω 与 α 的置信区间（见信度表）。**未提供**：分半信度、重测信度。若审稿人要求，可用 `psych::splitHalf()` 补充，并在论文中说明。
- **信度的正确理解**：α 是信度的**下限**（不满足 τ 等价假设时低估），且 α 高不等于量表好（可能题目冗余）。近年期刊更推荐报告 **ω**（不假设 τ 等价）。

### 5.5 效度证据

| 证据 | 工具输出 | 说明 |
|---|---|---|
| 效标关联效度 | `03_criterion_validity.csv` | 总量表与效标变量的相关 r、p，并检查方向是否符合预期（`criterion_direction: positive/negative`） |
| 已知组效度 | `03_known_group_validity.csv` | 两组用 Welch t + Cohen's d；多组用单因素 ANOVA + η² |
| 结构效度（EFA） | 见 5.6 | 探索维度结构 |
| 结构效度（CFA） | 见 5.7 | 验证：拟合指标 + CR/AVE + 判别效度 |

### 5.6 EFA（`goal: efa`）

**输出**：`04_efa_diagnostics.csv`（KMO、Bartlett）、`04_efa_variance.csv`（方差解释率）、`04_efa_rotated_loadings.csv`（旋转后载荷 + 共同度 + 主因子 + `suggest_delete`）、`04_efa_item_dimension_mapping.csv`（题目 → 维度映射）、`04_efa_deletion_history.csv`（建议删除清单）、`efa_scree_plot.png`、`efa_loading_heatmap.png`。

**实现要点**：

1. **适切性**：KMO（> .60 较好）与 Bartlett 球形检验。**它们是警告而非门槛**——即使不达标，工具也会完整输出结果，只是在日志中提醒"解读因子解需谨慎"（KMO 与 Bartlett 在现实中经常被误用为"能不能做因子分析"的一票否决）。
2. **因子数**：默认 `n_factors: auto` → 用**平行分析**（`psych::fa.parallel`，100 次模拟）确定，失败时回退到"特征值 > 1"（Kaiser 规则，已知会高估因子数）。可显式指定整数覆盖。
3. **抽取与旋转**：最小残差法（minres）+ 旋转（`promax` 斜交为默认，`varimax` 正交可选）。斜交默认更合理，因为心理学构念之间通常相关。
4. **建议删除规则**（**只标注，不自动删题**）：
   - 主载荷 < .40
   - 交叉载荷：次载荷 > .30 且主次之差 < .20
   - 共同度 < .20
   - 某个因子不足 3 题
   这些题会在载荷表中标记 `suggest_delete = TRUE`，并写入删除历史表，但**全部题目仍进入后续信度与 EFA 结果**。
   > ⚠️ **这是最重要的方法学提醒**：按数据删题属于"从数据里挑结果"，会高估后续信度与效度。请结合**内容效度**与理论决定是否删题，并在论文中**如实报告删题标准与删题前后结果**。
5. **碎石图**：画特征值曲线 + y = 1 参考线；**平行分析的建议因子数会打印在日志中**（可用它替代肉眼看拐点）。

### 5.7 CFA（`goal: cfa`）

**输入**：题目-维度对照表（两列 `item,dimension`，模板见 `examples\ctt_cfa_mapping_template.csv`）；模拟演示模式自动使用模拟真实结构。

**实现**：`lavaan::cfa(syntax, ordered = 所有题目, estimator = "WLSMV", std.lv = TRUE)`——即把 Likert 题目当作**有序分类变量**，用**对角加权最小二乘（WLSMV）**估计多分格相关矩阵。这是当前有序题目 CFA 的推荐做法（比把 5 点计分当连续变量更准确）。

**输出与判定**：

| 指标 | 阈值（工具标记） | 说明 |
|---|---|---|
| χ²/df | < 5 | 受样本量影响大，不能只看 χ² 的 p |
| CFI / TLI | > .90 | 越大越好；≥ .95 更严格 |
| RMSEA | < .08 | 建议同时报告 90% CI（工具目前只给点估计） |
| SRMR | < .08 | 残差相关均值 |
| 标准化载荷 | 全部 > .50（`all_loadings_gt_50`） | 载荷过低提示题目质量或维度归属有问题 |
| **CR（组合信度）** | > .70 | $CR = \frac{(\sum\lambda)^2}{(\sum\lambda)^2 + \sum(1-\lambda^2)}$，λ 为标准化载荷 |
| **AVE（平均方差抽取量）** | > .50 | $AVE = \frac{\sum\lambda^2}{k}$ |
| **Fornell-Larcker 判别效度** | √AVE > 该因子与其他因子的相关 | 输出 √AVE 矩阵与判定列 |

**还输出**：`05_cfa_model_syntax.lav`（可直接复用到 lavaan/Mplus 的模型语句）、`05_cfa_loadings.csv`、`05_cfa_factor_correlations.csv`、`cfa_path_diagram.png`（需安装 `semPlot`；缺失时会在日志中说明"未生成路径图"）。

**本工具已提供**：修正指数（`06_cfa_modification_indices.csv`）、Heywood case 显式告警。**未提供**（若研究需要请用 lavaan 直接补）：测量不变性检验（组间/跨时间）、HTMT 判别效度。

### 5.8 用模拟数据学"参数恢复"

`ctt_config.yaml` 的内置演示数据是按 **3 因子、15 题、载荷 .59–.78、因子相关 .30–.35、5 点有序化、1.8% 随机缺失、1 道反向题（Item5）** 生成的。你可以拿它做教学验证：

- 清洗后总量表 α 应为 **.8086**（工具数值回归测试的黄金值就是这个数）。
- CFA 路线：真值映射为 Item1–5 → F1、6–10 → F2、11–15 → F3（模拟模式下自动使用）。
- EFA 路线：平行分析应建议 **3 个因子**（实测确认）。
- 这叫**参数恢复（parameter recovery）**——用它验证流程走通、指标方向正确，比背阈值有效得多。

**`examples\simulated_datasets\` 里另有 5 组 CTT 数据**，各自针对一条此前没被覆盖的路径：

| 数据集 | 规模 | 专治什么 |
|---|---|---|
| **CTT-A** | 600 × 15 | 干净单维入门：信度、EFA、项目分析（α = .9187） |
| **CTT-B** | 500 × 20 | 完整问卷：三维 + 反向题 + 注意检验 + 反应时 + 效标 + 已知组 + 缺失 |
| **CTT-C** | 400 × 16 | 问题数据：坏题与脏作答，看"建议删题"机制 |

> CTT-E 的量表信度**刻意做低**（α ≈ .56）。原因见 §6.9 的同类分析：k 题 K 点量表的总分
> |z| 上限约为 `2/√(2·r̄)`，α ≥ .70 时上限只有 ~3.0，`|z|>3` 几乎不可能触发；
> 想演示"真的删掉极端个案"，就必须让量表的题间相关足够低。这条经验对真实数据同样成立。

## 第 6 章 IRT 分支：项目反应理论

### 6.1 什么情况该用 IRT（而不是 CTT）

- 你想知道**每道题的难度、区分度**，而不只是总分信度。
- 你想让不同被试**做不同的题**（计算机自适应测验 CAT、题库建设）。
- 你想把被试能力（θ）放在**题目难度（b）的同一把尺子**上，并给出测量标准误（SE）。
- 你想评估**测验信息函数**：这套题在哪个能力区间最精确。
- 注意：IRT 需要**更大的样本**（二分模型 ≥ 200–500，GRM/MIRT ≥ 500）和**局部独立性**假设，且题目数太少时参数估计不稳。

### 6.2 模型谱系（工具支持的全部模型）

| 模型 | 适用数据 | 参数 | mirt 中的写法 | 说明 |
|---|---|---|---|---|
| **Rasch** | 二分（0/1） | b | `itemtype="Rasch"` | **区分度 a 固定为 1**（真正的 Rasch 模型，实测确认 a 极差 = 0）；题目难度可直接与能力比较，量表化最好 |
| **2PL** | 二分 | a, b | `itemtype="2PL"` | 允许题目区分度不同（实测恢复 a ∈ [0.81, 2.08]） |
| **3PL** | 二分 | a, b, c | `itemtype="3PL"` | 增加**猜测参数 c**。显式写 `model: 3pl` 一定能拟合；`allow_3pl`（默认 false）只决定 `model: auto` 时 3PL **是否进入候选**（且需 n ≥ 500）。c 是最难估的参数，见 §6.9 |
| **GRM** | 有序多级（1–5 等） | a, b₁…b_{K−1} | `itemtype="graded"` | 等级反应模型（Samejima 1969 累积 logit），有序题目最常用 |
| **GPCM** | 有序多级 | a, b₁…b_{K−1} | `itemtype="gpcm"` | 部分计分/逐步作答模型（Muraki 1992 **相邻类别** logit）。与 GRM 的区别在"台阶"的累积方式：GRM 假设各步难度有序，GPCM 允许逐步得分。多级数据建议两个都拟合、按 BIC 选（`compare_models: [grm, gpcm]`） |
| **MIRT-EIFA** | 二分或多级 | 多维载荷 | `mirt(x, d)` 多因子自由估计 | 探索性：试 1…max 个维度，**按 BIC 选最优**。家族由 `mirt_item_model` 指定：`2pl`（M2PL，二分）｜`3pl`（M3PL，二分）｜`grm`（MGRM，多级）｜`gpcm`（MGPCM，多级）｜`auto` 按计分类型自动匹配 |
| **MIRT-CIFA** | 二分或多级 | 指定结构载荷 | `mirt(x, model_syntax)` | 验证性：按对照表固定结构，并与**单维模型**比较（ΔCFI/ΔRMSEA/ΔAIC/ΔBIC）。家族同上 |

### 6.3 参数怎么读（含公式）

- **a（区分度 / slope）**：题目对能力变化的敏感度。越大越"陡"。
- **MDISC（多维区分度）**：$MDISC = \sqrt{\sum_j a_j^2}$。单维时等于 a。
- **b（难度 / 阈值位置）**：$\;b_k = -d_k / MDISC$。工具输出的 `MDISC`、`b_d1…b_dK` 列就是这个换算。
  > **已实测验证**：工具的 $b = -d/MDISC$ 与 mirt 自己的 `coef(IRTpars = TRUE)` **完全一致（最大绝对差 = 0）**。
  > **GPCM / MGPCM 的 b 与 GRM 不是同一种量**：GRM 的 d_k 本身就是阈值，`b_k = -d_k/MDISC`；
  > 而 GPCM 的 d_k 是**类别截距**（参考类别 d₀ ≡ 0），标准台阶难度是**相邻截距之差**
  > `b_k = -(d_k - d_{k-1})/MDISC`。工具输出的 `b_d1…b_d_{K−1}` 用的就是台阶口径
  > （不会输出恒为 0 的 `b_d0`）。已实测：单维 GPCM 下工具的 b 与 mirt 自己的
  > `coef(fit, IRTpars = TRUE)` 逐题相同（最大绝对差 5×10⁻¹⁵）。
  > **多维情形**：mirt 对多维 GPCM 的 `IRTpars` 直接返回 `NA`（没有单一口径的"难度"），
  > 此时工具的 `b_d*` 是自身定义（相邻截距差 / MDISC），只能与生成真值核对，不能与 mirt 对照。
  > **多维数据的细节**：模拟数据生成时阈值是按主维度载荷放置的（$d = -b \times a_{primary}$），而输出按 MDISC 折算，因此**多维情形下恢复出的 b 与生成真值会有约 5% 的小差异**（实测 Item1 前三个阈值：真值 −0.659/−0.472/0.545，恢复 −0.692/−0.486/0.575）。这不是 bug，是"多维合计区分度"与"主维度区分度"两种口径的差别，写论文时应说明用的是哪一种。
- **多级题目的 b₁…b_{K−1}**：相邻类别之间的"台阶"位置，应**单调递增**（工具输出的 b 列按升序排列）。
- **能力 θ**：工具用 **MAP（最大后验）** 估计，同时给出每人的 SE。实测 1D GRM（15 题，n = 1000）θ 恢复 **r = .934、回归斜率 0.863、平均 SE = 0.342**——斜率略小于 1 是 MAP 的先验收缩（shrinkage）造成的正常现象。若追求无收缩的点估计，可用 EAP（mirt 默认）；想要与 CTT 总分相关性更高的可用 WLE。
- **ICC / IIF / TIF**：题目特征曲线、题目信息函数（$I(\theta)=\sum_k \frac{(P_k')^2}{P_k}$）、测验信息函数。**注意**：多维模型中曲线是"其它维度固定在 0"的**条件切片（conditional slices）**，图的标题已注明；解读时不要说成"总体信息"。

### 6.4 模型选择

- **向导**（GUI 首步「模型选择向导」/ 终端「向导推荐」）：按 计分类型 → 维度 → 样本量 →
  （多级）作答方式 /（二分）特殊情况 依次提问；**选“多维”时追加两问**（EIFA/CIFA 模式、
  M2PL/MGRM/MGPCM/M3PL 家族），共 3–5 问给出带文献依据的推荐，并自动回填模型与 `mirt_item_model`。
- `model: auto` 时：
  - 二分数据 → 候选 `rasch`、`2pl`（若 `allow_3pl: true` 且 n ≥ 500 再加 `3pl`），当维度建议 > 1 时再加 `mirt`。
  - 多级数据 → 候选 `grm`（维度 > 1 时加 `mirt`）。
  - **按 BIC 排序选最优**（可用 `selection_criterion` 改为 AIC/SABIC），结果写入 `*_model_comparison.csv` 与 `*_model_recommendation.csv`，并在日志中打印 `AUTO_BIC_RANKING=`。
- **候选模型**：`compare_models: [rasch, 2pl, 3pl]` 一次拟合多个并比较。
- **拟合指标**：logLik、−2LL、AIC、BIC、SABIC；`compute_m2: true` 时额外算 **M2\*** 绝对拟合（RMSEA/TLI/CFI/SRMSR）。
- **题目拟合**：默认输出 **S-X²**（有序数据的题目拟合统计量）并做 **BH 多重比较校正**（`*_item_fit.csv` 的 `BH_p` 列）。
- **维度建议**：EIFA 的候选维度来自 `dimension_range`（如 `1-3`）或默认范围；启发式的维度建议 = **平行分析**（`psych::fa.parallel`，对主成分特征值，100 次模拟），失败时退回 Kaiser 规则，并受 `max_auto_dimensions` 上限约束。**最终维度数仍由 BIC 比较决定**。
  > 注意：对**二分数据**，平行分析基于 Pearson 相关（不是四分相关），只是启发式，不要把它的建议当成结论。

### 6.5 缺失值：三种策略的**真实**语义（重要）

| 配置 | 实际行为 | 影响 |
|---|---|---|
| `none`（默认） | **不预处理**，把 NA 交给 mirt：用**观测反应似然**（EM 边际化）处理缺失 | 保留全部被试；MAR 假设下是正确做法 |
| `pairwise` | **与 `none` 完全相同**（代码里只有 `listwise` 会真正删数据）；仅维度启发式使用成对完整的相关矩阵 | 计算结果与 `none` 一致，只有报告里的说明文字不同 |
| `listwise` | **先删掉任何有缺失的被试**再拟合，删了多少人记录在 `*_missingness_summary.csv` 的 `Listwise_removed` | ⚠️ 代价极大：**实测 15 题、随机 8% 单元格缺失时，会删掉 73% 的被试**（1000 → 267 人） |

> **实践建议**：除非缺失机制特殊（如整段未答），优先用 `none`；报告时写清"缺失由边际极大似然处理"。如果非要用 listwise，请在论文中报告删除比例，并做敏感性分析。

**读审计表时必须知道的两件事**（实测确认）：

1. `*_missingness_summary.csv` 里的 `Missing_cells` / `Missing_pct` 统计的是**删除之前**的缺失情况，而 `Analysed_N` / `Listwise_removed` 是**删除之后**的结果。所以 listwise 下可能出现"`Missing_pct = 5` 但 `Analysed_N = 107 / 200`"这种看起来矛盾的组合，这不是错误。
2. 如果有被试**一道题都没答**（整行全缺失），工具不会拦截：他们的 θ 与 SE 会写成 `NA`，而能力汇总表用 `na.rm = TRUE` 统计，因此**报告文字里的"进入模型估计的被试数"会多于实际参与汇总统计的人数**（实测：报告写 200，汇总实际基于 197 人）。写完 IRT 报告前，请打开 `*_ability_estimates.csv` 检查有没有 `NA` 行。

### 6.6 数据体检（`irt_preflight.R`）

IRT 分支在分析前后会做一次独立的数据体检（GUI 与启动器都会调用），产出 JSON（含 `status`、`fatal`、`warnings`），检查内容包括：

- **致命**：整题全缺失、零方差题、所选模型与计分类型不匹配（如多级数据选 2PL）、MIRT 的载荷矩阵/维度范围非法。
- **警告**：总体缺失率 > 10%、单题缺失率 > 20%、存在极少使用的反应类别（< max(5, 1% N)）、MIRT 样本 < 200。

> 这是三个分支里**唯一**做到"分析前先把数据格式挡住"的体检机制（心理统计与 CTT 分支没有同等的前置校验）。

### 6.7 输出怎么用

- `*_item_parameters.csv`：a₁…a_D、MDISC、b_d1…b_dK、`Primary_dimension`（按 |a| 最大的维度判定）→ 论文里的题目参数表。
- `*_ability_estimates.csv`：每人的 θ 与其 SE（若配置了 `id_column` 会把被试编号带上）→ 可导出做后续分析（如作为因变量做回归）。
- `*_item_fit.csv`：S-X² 与 BH 校正 p → 报告"所有题目拟合良好"的依据。
- `*_icc.png` / `*_iif.png` / `*_tif.png`：300 dpi 图，可直接进论文（记得在表注里说明多维情形下是条件切片）。
- `*_simulation_truth.csv` / `*_simulation_true_theta.csv`（仅模拟模式）：**真值与真 θ**——用来做参数恢复教学。
- `*_selected_model.rds`：mirt 拟合对象，可在 R 里继续做 DIF、局部依赖等进阶分析。

### 6.8 IRT 的局限（务必写进论文的"限制"部分）

- 工具**不做** DIF（差异题目功能）分析、局部依赖检验、测验等值/链接（linking）、CAT 选题。这些需要额外分析（mirt 的 `DIF()`、`residuals()` 等）。
- 模型选择基于 BIC/AIC 等**统计准则**，不能替代理论：维度数的最终判断必须结合构念理论。
- 参数估计依赖样本量与题目质量；小样本或全对/全错题会导致参数不稳（工具会挡住零方差题，但"接近全对"的题仍可能估出极端参数）。
- θ 的 MAP 估计有收缩，跨样本比较能力均值时要谨慎。

### 6.9 实测经验：3PL 的猜测参数、GPCM 的台阶、以及 EIFA 的 θ

以下数字都来自本目录 `examples\simulated_datasets\` 里的模拟数据（生成真值已知，故可做参数恢复）。

**① 3PL 的猜测参数 c 很难估，BIC 也未必认得出真模型**（IRT-H：N=1500、20 题、真值 c ∈ [0.08, 0.25]）

| | 按 3PL 拟合 | 按 2PL 拟合（忽略猜测） |
|---|---|---|
| a 恢复 | *r* = .770 | *r* = .536 |
| b 恢复 | *r* = .964，**平均偏差 +.061** | *r* = .986，**平均偏差 −.285** |
| **c 恢复** | ***r* = −.406**（均值 .168 vs .171 很准，但个体排序是乱的） | — |
| BIC（并列比较表） | 33641.5 | **33561.2 ← 2PL 的 BIC 更低**（配置里显式写了 `model: 3pl`，故实际仍按 3PL 出结果；若改成 `auto` 就会被判成 2PL） |

结论：**忽略猜测会系统性低估题目难度**（−0.285 logit），但**逐题的 c 基本上不可用**——
这次 N=1500 仍不足以让 BIC 站到 3PL 这边（若把 `model` 交给 `auto`，选出来的会是 2PL）。报告里若写逐题 c，必须标明它是弱识别参数。

**② GPCM 的台阶 b 与 GRM 不是同一种量**（IRT-G：三维 GPCM，N=900、24 题）

- mirt 的 GPCM 参数是**类别截距** d_k（参考类别 d₀ ≡ 0），台阶难度 = 相邻截距之差 ÷ MDISC。
  照搬 GRM 的 `-d_k/MDISC` 会得到"累积和"：既不单调也没有台阶含义。工具已按台阶口径输出 `b_d1…b_d_{K−1}`。
- 实测：单维 GPCM 下工具的 b 与 mirt `coef(fit, IRTpars = TRUE)` **逐题相同（最大绝对差 5×10⁻¹⁵）**；
  **多维 GPCM 时 mirt 的 `IRTpars` 返回 `NA`**，此时只能与生成真值核对（本次台阶恢复 *r* = .995、RMSE ≈ .12）。

**③ EIFA 的 θ 不能逐因子比对，CIFA 的可以**

同一份三维 GPCM 数据：

| | 题目参数（a / 台阶 b） | θ 恢复（逐因子） |
|---|---|---|
| EIFA | *r* = .87 / .995 | *r* = **.41 / .49 / .40** ← 因子经斜交旋转，顺序与取向不固定 |
| CIFA | *r* = .85 / .995 | *r* = **.94 / .93 / .94** |

EIFA 是探索性的，它的因子会旋转，逐因子去追生成时的 F1/F2/F3 没有意义；
要得到可解释、可跨样本比较的维度分数，请用 **CIFA + 题目-维度对照表**。
二维二分数据（IRT-I）上是同一个规律：EIFA 的 θ *r* ≈ .61，CIFA 的 θ *r* ≈ .87。

## 第 11 章 已知限制与注意事项（请务必读）

### 11.1 方法学层面的诚实清单

1. **"与 SPSS 逐位对照"目前是代码级对齐，不是外部基准比对**。仓库里没有 SPSS 输出夹具（fixture）。建议：把十几张 SPSS 原始输出截图/表格存进 `tests/fixtures/spss/`，与对应 CSV 做成断言。**在此之前，正式发表前请手工抽查关键表格**。
2. **数值回归测试只覆盖 21 个模块中的 6 个**（独立 t、单因素 F、配对 t、重复测量 F、卡方独立性、中介 ab），加 CTT 的 α 与 3 条 SPSS 对齐断言；其余 15 个模块没有数值断言。
3. **CTT 的 EFA 路线里，分量表 α 用的是同一批数据探索出的维度**——循环性会使其偏乐观；建议在独立样本上验证结构后再报分量表信度。
4. **EFA 的"建议删题"是推断性标记**，不是客观结论；删题会高估后续信度/效度。
5. **IRT 的 `pairwise` 与 `none` 计算结果完全相同**（只有报告文字不同）；`listwise` 在缺失分散时删除比例可能极高（实测 8% 单元格缺失 → 删 73% 被试）。
6. **IRT 的能力估计是 MAP**，存在向先验收缩（斜率约 0.86），比较不同样本的 θ 均值时要谨慎。
7. **CAT/多维 θ 的相关取值**：多维模型中 ICC/IIF/TIF 是"其它维度固定为 0"的条件切片。
8. **已具备**：McDonald's ω、α 置信区间（`scripts/ctt_pipeline.R` 的 `omega_1f` 与 `alpha_ci_lower/upper`）、CFA 修正指数（`06_cfa_modification_indices.csv`）。**仍然没有**：分半/重测信度、HTMT、测量不变性、IRT 的 DIF/局部依赖/等值。
9. 多选题、计时反应时数据、多层数据（嵌套设计）不在支持范围内。

10. **输出正确性的独立验证状态（2026-09-18）**：CTT 与 IRT 的输出已按三层判据复核——**闭式复算**（用教科书公式从原始数据/参数表重算每个输出量）、**已知真值恢复**（与模拟数据的生成参数比）、**独立实现对照**（换 `ltm`/`TAM` 等第二实现重跑），并由两个外部模型（GLM-5.3、GPT-5.6 Terra）以实跑方式独立复核两轮。**结论：未发现任何已证实的数值错误**；全部实测数字见 `docs/CTT与IRT校对记录.md`（Word 版在项目根目录）。
    - **已验证的关键项**：CTT 的 α、CITC、CR 决断值、KMO、Bartlett、EFA 表一致性、CFA 的 CR 与 AVE、ω、α 的 Feldt 精确区间，以及**清洗链路逐行复现**（5 个数据集、0 处不一致）；IRT 的 MDISC、b↔d 换算（含 GPCM 台阶口径）、ICC、IIF、TIF、缺失勾稽、BH 校正、题名口径。
    - **独立实现对照的结果**：单维 2PL/GRM 与 `ltm` 的 a、b 及阈值 **r = 1.0000**；单维 GPCM 与 `TAM` 的 a **r = .999996**；二维 GPCM 与 `TAM` 的 a **r = .9977**、台阶 **r ≥ .9997**（量尺对齐后 b_d4 平均差 .0513，略高于 .05 的建议线，属边界值）；单维 2PL 的 SRMSR 在两引擎间相差 **5.0e-05**。
    - **尚未独立验证的区域（均为已分析过的技术原因，不是遗漏）**：
      ① **三维及以上多维 GPCM** 无第二实现对照——可用的第二引擎 TAM 在 3 维 × 24 题规模下不收敛（n=150 时 380 秒未返回），2 维子模型可秒级完成；故三维 MGPCM 目前只有闭式自洽与真值恢复两类证据。补齐路径：安装 `sirt` 等可收敛的第二引擎。
      ② **有序题 CFA** 无第二实现对照——lavaan 的 WLSMV 在本机没有等价第二实现：`OpenMx` 的 `mxFitFunctionWLS(type=)` 只提供 `WLS/DWLS/ULS`（已核对函数签名），没有 WLSMV 的均值/方差修正；`semTools` 是 lavaan 的插件，不构成独立引擎。若确需第三类证据，只能改走"两侧同为连续 ML"的口径（工具在题目唯一取值 > 10 时即用 ML），此时结果与 WLSMV 口径不完全可比。
      ③ **`M2*` 及其 df、`TLI`、`CFI`** 无第二实现对照——TAM 不输出这些量；只有 SRMSR 可作数值对照（差 5.0e-05），而 SRMR 在两引擎的定义不同，不可逐位比。
      ④ **多维模型的能力标准误**与跨 `mirt`/`psych` 版本的行为未做对照（前者已论证：工具的 TIF 是"其它维度固定为 0"的条件切面，与完整信息矩阵的 SE 不存在等式关系）。
