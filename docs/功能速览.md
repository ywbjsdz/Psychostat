# Psychostat 功能速览（3 分钟看完）

> 这份是"懒人版"。想看完整的（每个方法怎么解释、怎么写结果段）再翻《Psychostat完整使用说明书.docx》。

## 一句话

**把 SPSS 式的经典统计、量表编制（CTT）、项目反应理论（IRT）三件事，做成了一个 Windows 上双击就能用的小工具。**
不用装 SPSS、不用配 R 环境（随包自带），跑完自动出表格、图、Word/HTML 报告，还告诉你"结果怎么写"。

## 30 秒上手

1. 把压缩包里的**三个文件夹**一起解压到 **D 盘根目录**（`D:\Psychostat`、`D:\Psychostat-R`、`D:\Psychostat-Python`）。
2. 双击 `D:\Psychostat\启动Psychostat界面.bat`。
3. 左边选一条线 → 跟着步骤点 → 跑完自动打开报告。

> 先花 1 分钟双击一次 `运行离线自检.bat`：不联网、跑完一堆 `[PASS]` 就说明你电脑没问题。

## 三条线分别能帮你干什么

| 你手头的情况 | 用哪条线 | 它会给你什么 |
|---|---|---|
| 课程作业：t 检验、方差分析、相关回归、卡方、非参数、中介/调节 | **① 心理统计** | 21 个方法的完整结果表＋图，**每个都写着 SPSS 菜单在哪、结果怎么读、结果段怎么写** |
| 我在编/改一份量表，想知道题目好不好、信效度够不够 | **② 量表编制 CTT** | 清洗数据 → 逐题分析（该不该删题）→ 信度（α、ω）→ 效度（EFA 找结构 / CFA 验证结构）→ 报告初稿 |
| 我要做 IRT（题库、难度区分度、能力估计），或老师要求做 IRT | **③ 项目反应理论 IRT** | Rasch / 2PL / 3PL / GRM / GPCM / 多维 IRT，含题目参数、ICC/IIF/TIF 图、每人的能力分与标准误 |
| 不确定选哪个 | 从 **①** 开始 | 界面上每一步都有中文说明；选错了它也会告诉你为什么不能用 |

## 术语 30 秒白话版（不用背，知道大概就行）

| 术语 | 大白话 |
|---|---|
| **心理统计** | 你统计课上学的那些检验：两组比、多组比、看相关、做回归…… |
| **CTT（经典测量理论）** | 最传统的量表评价法：**看总分**。题目跟总分越一致、整体越稳定，量表就越"可信" |
| **IRT（项目反应理论）** | 更现代的测量法：**不看总分**，而是给每道题算"难度"和"区分度"，再据此估计每个人的能力 |
| **α（克隆巴赫系数）** | 常说的"信度"。越大越一致（一般 ≥.70 算可以，≥.80 较好） |
| **CITC** | 某道题和"其余题总分"的相关。太低（<.30 左右）说明这题跟大家不合群 |
| **EFA / CFA** | EFA＝**探索**数据里有几个维度（不知道结构时用）；CFA＝**验证**你预设的维度对不对（有理论时用） |
| **Rasch / 2PL / 3PL** | 二分题（对/错）的三代模型：Rasch 最简单（只算难度）、2PL 加区分度、3PL 再加"蒙对的可能" |
| **GRM / GPCM** | 多级题（比如 1–5 分）的两套常用模型，区别在算法细节；**样本够时两个都跑，用 BIC 比一比** |
| **MIRT / EIFA / CIFA** | 多维 IRT：一道题同时测多个维度。EIFA＝探索维度，CIFA＝按你给的对照表验证 |
| **θ（能力分）** | IRT 给每个人算的"潜在水平"，类似标准分 |
| **ICC / IIF / TIF** | 三条曲线：单题的作答概率曲线 / 单题提供的信息量 / 整卷的信息量 |

## 每个方法都会给你的东西

- **结果表**：可直接抄进论文的三线表（SPSS 口径，方便你在 SPSS 里复核）
- **图**：300 dpi，能直接插进 Word（碎石图、载荷、ICC/IIF/TIF、中介路径图等）
- **报告**：中文 Word + 网页版，含"结论句模板"，把构念名换掉就能用
- **可追溯**：所有数字都能在结果目录的 CSV 里找到，审稿人问起来能指回去

## 练手数据（不用自己找数据）

- `examples/simulated_datasets/`：**14 组模拟数据**，每组都带"生成真值"和现成配置——**可以先看"标准答案长什么样"，再代入自己的数据**
- `examples/手动走查数据/`：**18 个按功能分好的 CSV** + 一张对照表（每个文件该勾什么选项）。想"把三条线都点一遍"就用这套

## 最容易踩的 5 个坑

1. **解压位置**：三个文件夹必须一起放在 **D 盘根目录**，别只解压内层文件夹、别放 OneDrive。
2. **被 Windows 拦**：较新的 Win11 可能开着"智能应用控制"，会拦住随包 R 的一个文件——**症状是统计和 CTT 能跑、一跑 IRT 就报错**。解决办法见《免责声明（必读）.txt》第 1 节。
3. **数据格式**：一行一名被试、一列一道题；**题目列只放题目**（姓名、学号、时间戳要标成"不分析"）。列名别用 `-`、空格、顿号。
4. **缺失与反向题**：反向题一定要在向导里勾上，最高分要填对（0–4 编码就填 4）；高缺失个案的 listwise 删除会很"狠"（实测 8% 分散缺失就能删掉八成个案），报告里能提前看到。
5. **别把工具当结论**：它负责算，结论由你负责。**关键数字（样本量、信度、检验统计量）请自己核一遍**；正式发表前更要点检。不得用于临床诊断、人员选拔等高风险决策。
